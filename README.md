# Jardim Check

Projeto PWA para autoinspeção sanitária da Padaria e Confeitaria Jardim.

## Funcionalidades
- Dashboard com indicadores
- Seleção de setor, responsável e data
- Checklist específico por setor
- Validação de respostas e evidência fotográfica
- Cálculo do índice de conformidade
- Plano de ação com responsável, prazo e status
- Relatório final com impressão/PDF
- Histórico no LocalStorage
- Instalação como app com PWA

## Como executar localmente
1. Abra a pasta do projeto.
2. No terminal, execute:
   python -m http.server 8000
3. Acesse:
   http://localhost:8000

## Como publicar no Vercel
1. Crie um novo repositório GitHub.
2. Envie os arquivos do projeto.
3. Conecte o repositório ao Vercel.
4. Faça o deploy padrão.
5. Acesse o link HTTPS gerado pelo Vercel.

## Instalar no celular
No navegador do celular, ao abrir o site em HTTPS:
- Android: menu do navegador → “Adicionar à tela inicial”
- iPhone: botão de compartilhar → “Adicionar à Tela de Início”

## Observação
Os dados ficam salvos localmente no navegador via LocalStorage.
